# 树洞信箱 · 校园心理倾诉与预警系统

> 给学生在手机上一个随时能说说话的树洞，给心理中心一块能看见整体情绪的看板。
> Node.js + Express + SQLite 单进程实现，一条命令跑起来，学生端与中心端同时可用。

---

## ⚠️ 免责声明（请先读一遍）

本系统面向**校园心理健康辅助场景**，提供情绪记录、AI 倾诉陪伴、心理量表自评与情绪聚合看板。

- 它**不是医疗器械，不构成任何医疗诊断、治疗建议或心理疗效承诺**；AI 的回答不代表专业诊疗意见。
- 遇到紧急情况（自伤念头、严重睡眠/饮食障碍、持续强烈痛苦等），请**立即联系学校心理中心、精神科门诊或拨打当地心理援助热线**。
- 部署方有责任按《个人信息保护法》等法规做好数据的采集告知、最小必要与留痕；**上线前请自行完成校园伦理与合规审查**。
- 本项目代码开源，不代表使用者的部署方式合规。**风险与责任在用方。**

## 一、它做什么

| 端 | 能力 |
|---|---|
| 学生端（移动优先 Web） | 情绪打卡 → 对话式倾诉 → 四阶流程陪伴 → PHQ-9 / GAD-7 小测自评 → 未来信 → 呼吸放松卡片 → 匿名留言 |
| 心理中心端 | 情绪趋势看板、 Neg 情绪占比聚合、预警台账、干预登记、知识库维护、AI Key 集中管理 |

**多 Agent 设计**：同一场对话里按需要切换三种人格——

- **小陪**：倾听型，短句、不评判，负责把情绪接住；
- **小咨**：知识型，接知识库做具体议题回应；
- **小测**：量表型，只负责 PHQ-9 / GAD-7 逐题推进，收分后给一段总结。

三者共享同一段会话历史，但**互相看不见对方的原话**（跨 Agent 上下文隔离），避免人格串台。

知识库内容围绕 Yalom 存在主义治疗框架与高校心理健康常识整理改写，覆盖学业压力、宿舍人际、孤独感、自我怀疑、就业迷茫、情感困扰、拖延等常见议题。

## 二、快速开始

### 2.1 环境要求

- **Node.js 18 – 22**（推荐 20 LTS）：[nodejs.org](https://nodejs.org/) 下载 LTS 版本，一路"下一步"装完即可，**不用改任何选项**。装完重启一次电脑，让 PATH 生效。
- 无需数据库服务，SQLite 是本地文件库，开箱即用。
- 磁盘上只需留 `树洞信箱Web版` 整个文件夹，**不要单独拷出 `server` 目录**。

> ⚠️ **为什么推荐 20 LTS**：项目依赖 `better-sqlite3`（SQLite 的原生模块）。早期 11.x 版本在 Node 23/24 上没有预编译二进制，
> 会静默跳过编译、启动时抛 `ERR_DLOPEN_FAILED`。新装的 `11.10.0` 已补上 Node 24 的预编译，实测可用；
> 且启动脚本已内置自检：双击启动时会自动检测原生模块与当前 Node 版本是否匹配，不匹配会自动重装修复（需联网，约 1 分钟），
> 因此 Node 24 下也能直接跑。为稳妥起见，新手仍建议按 20 LTS 走。

### 2.2 Windows：双击启动

1. 进入 `树洞信箱Web版` 文件夹，**双击 `启动树洞信箱.bat`**；
2. 黑窗口会自己找 Node、装依赖、校验原生模块与 Node 版本是否匹配，**首次运行约需 1–2 分钟（属正常，请耐心等，不要提前关窗口）**；
3. 窗口里出现"树洞信箱已启动"即成功。

| 端 | 地址 |
|---|---|
| 学生端 | <http://localhost:3000/> |
| 心理中心端 | <http://localhost:3000/center> |

**停止服务**：关掉黑窗口，或在窗口里按 `Ctrl + C`。

> ⚠️ **数据集青龙在这里——`node_modules` 别被复制残缺**。整个文件夹在机器之间拷贝（U 盘、微信传、网盘同步、解压缩包）时，
> 若源目录的 `server/node_modules` 本身就是不完整的，复制过去还是残的。而启动脚本的判断是
> **"看到 `node_modules` 文件夹存在就跳过安装"** → 于是跳过安装直接启动，报 `Cannot find module 'express'`。
> **解决办法**：删掉 `server/node_modules` 整个文件夹，重新双击启动脚本即可（会自动重装）。
> 换句话说：**依赖目录宁缺勿残——掐掉重装，别带着残缺跑。**

### 2.3 Linux / macOS：一条命令

```bash
cd 树洞信箱Web版
bash 启动.sh
```

同样会先装依赖再起服务，端口 **3000**。跑完按 `Ctrl + C` 停止。

### 2.4 手动运行

```bash
cd 树洞信箱Web版/server
npm install
node server.js
```

数据库在首次启动时自动创建（`server/shudong.sqlite`），并从 `树洞信箱_知识库_ima补充.json` 灌入知识库种子。

> 想灌一批脱敏示例数据用于演示：`node ../seed.js`（`server/seed.js`）。
> 数据库位置可用环境变量 `DB_PATH` 覆盖，例如 `DB_PATH=%LOCALAPPDATA%\shudong.sqlite`。

> ⚠️ **数据库在哪，取决于你怎么启动**——这是个容易误会的点：
> - **双击 `启动树洞信箱.bat`**：脚本把 `DB_PATH` 固定为 `%LOCALAPPDATA%\shudong.sqlite`
>   （见脚本第 8 行）。所以**同一台机器上任何位置的副本，用 bat 启动都读写同一份数据**；
>   想让某个副本拥有独立数据，把第 8 行改成 `set "DB_PATH=%~dp0server\shudong.sqlite"`。
> - **手动 `node server.js` 或 `bash 启动.sh`**：不设 `DB_PATH`，数据库落在各自目录的 `server/shudong.sqlite`，各副本数据互不干扰。

### 2.5 三分钟演示路线

想快速看完整效果，按这个顺序走一遍（**学生端用手机浏览器或浏览器的手机模式打开**）：

1. 打开学生端 <http://localhost:3000/>，先做一次情绪打卡；
2. 进对话，输入一段真实的困扰试试，例如：
   > 最近总是睡不好，一躺下就胡思乱想，白天上课也没力气，感觉什么都很麻烦。
   小陪会按「倾听 → 澄清 → 反映 → 陪伴」四阶回应（短句、不评判）；
3. 接着问一句：「那我这种情况需要看医生吗？」——小咨会带着知识库给出具体议题回应；
4. 让小测走一遍 PHQ-9（9 题），收分后会给一段总结；中间可打开呼吸放松卡片；
5. 打开心理中心端 <http://localhost:3000/center>，用管理员口令登进去，
   看情绪趋势与 Neg 占比聚合、预警台账，并登记一条干预；
6. 想让看板一开始就有数据：把 `启动树洞信箱.bat` 第 7 行改成 `set "AUTO_SEED=1"`，重开窗口即可。

> ⚠️ 第 2–4 步依赖大模型 Key。复制 `keys.json.example` 为 `keys.json` 并填入自己的 Key 后重启脚本，
> AI 对话与语音识别才可用；没配 Key 时相关接口返回 503，两端其余功能不受影响。

### 2.6 卡住了？先查这张表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击黑窗口**一闪而过**，报 `Cannot find module 'express'` | `node_modules` 复制残缺，脚本以为已装依赖就跳过了安装 | 删掉 `server/node_modules` 整个文件夹，重新双击 |
| 提示 `[错误] 未找到 Node.js` | 没装 Node，或装完没重启电脑 | 装 20 LTS，**重启电脑**后再双击 |
| 装依赖卡住 / 装到一半失败 | 网络问题 | 检查网络后重新双击（会续着装，不必删目录） |
| 启动报错 `ERR_DLOPEN_FAILED` / `NODE_MODULE_VERSION` | `better-sqlite3` 原生模块与当前 Node 版本不匹配（多发生在**复制文件夹**或换 Node 之后） | 新版脚本会自动检测并修复（约 1 分钟）；若自动修复仍失败，删掉 `server/node_modules` 后重新双击 |
| 报 `EADDRINUSE`（端口被占用） | 3000 端口被别的程序占了 | 改 `启动树洞信箱.bat` 第 6 行 `set "PORT=3000"`，换个数字如 3001，然后访问 `localhost:3001` |
| 浏览器打不开 `localhost:3000` | 黑窗口已经关了，或端口改了 | 保持黑窗口开着；改了端口就访问新端口 |
| 中心端一直弹登录框、且**永远登录失败** | 用 `file://` 直接双击了 `server/center.html`，浏览器拦掉了接口请求 | 一律走 http://localhost:3000/center |
| `Mac / Linux` 下双击 `.sh` 没反应 | 脚本需要 shell 执行 | 终端里 `cd 树洞信箱Web版` 再 `bash 启动.sh` |
| 学生端看不到之前的记录 | 打卡记录存在**浏览器 localStorage** 里，不在数据库 | 学生端按 `F12` → Console → 输入 `localStorage.clear()` → 回车 → 刷新 |
| 打开看板看到一堆示例数据，以为没清干净 | `AUTO_SEED` 打开了自动灌演示数据 | 改 `启动树洞信箱.bat` 第 7 行 `set "AUTO_SEED=0"`；想手动灌数据就在 `server` 目录跑 `node seed.js` |
| 想看口令登录页 | 默认演示态免登录 | 见第四章「配置说明」里的本地演示口令表 |

## 四、配置说明

| 配置项 | 位置 | 说明 |
|---|---|---|
| 大模型 Key | 项目根 `keys.json`（模板见 `keys.json.example`，复制后填值；也可由中心端「Key 管理」面板热更新） | 最小可用 = 1 条 `deepseek`（对话）+ 1 条 `glm`（语音识别）；不配置时 AI 相关接口返回 503，其余功能正常 |
| 管理员口令 | 环境变量 `ADMIN_PASS` | **本地演示值 `admin2026`**（全权限）；不设 = 演示态打开即进；设了则强制口令登录 |
| 咨询师口令 | 环境变量 `COUNSELOR_PASS` | **本地演示值 `counselor2026`**（只读看板 + 干预登记） |
| 会话密钥 | 环境变量 `SESSION_SECRET` | 生产环境务必设置，防止会话 Cookie 被伪造 |
| 数据源 | 环境变量 `DB_PATH` | 默认 `server/shudong.sqlite` |
| 演示数据 | 环境变量 `AUTO_SEED` | 一键启动脚本默认 `0`（不灌数据）；想看示例数据改成 `1` 后重启 |

**口令安全**：`server.js` 内置 fail-closed 自检，`admin` / `user` / `123456` / `password` / `changeme` / `root` / `shudong` 这类弱口令会**直接拒绝启动**。想部署到公网，请自行设置 20 位以上随机强口令——自检只拦已知弱值，剩下的要人工把关。

**本地演示口令（双角色，开箱即用）**

| 角色 | 口令 | 权限 |
|---|---|---|
| 管理员 | `admin2026` | 全权限：情绪看板 / 知识库 / Key 管理 / 清空数据 |
| 咨询师 | `counselor2026` | 只读看板 + 干预登记 |

`启动树洞信箱.bat` 里已经默认写好了这两行，双击启动后打开中心端会直接弹出登录页，照上表填进去即可。想换成自己的口令，直接改 bat 里 `ADMIN_PASS` / `COUNSELOR_PASS` 两行的值即可。

> ⚠️ 这两组口令已在本仓库文档中公开，仅适用于本地 / 演示环境；部署到公网请换成 20 位以上随机强口令。`admin2026` / `counselor2026` 不在 fail-closed 自检名单里，后端拦不住，只能靠人工把关。

> ⚠️ 不要直接双击 `server/center.html`（`file://` 方式打开会被浏览器拦下接口请求，页面会弹出一个**永远登录失败**的登录框）。一律通过 http://localhost:3000/center 访问。

## 六、数据与隐私

- 所有业务数据落在 SQLite 本地文件，**不依赖外部数据库**；
- 学生端聊天记录默认可脱敏处理，`clear_data.js` 提供一键清空上报数据；
- `keys.json`、口令、日志与 `*.sqlite*` 均在 `.gitignore` 中排除，**请勿手动提交**（一旦推到公开仓库就等于泄露）；
- 心理相关数据的保存期限、导出与删除策略，请按所在学校规定配置。
